# AI Agents Library for CentaurOS

This directory contains specialized AI agent configurations that Founders can deploy to automate and augment various business functions.

## Agent Categories

### Engineering (`engineering/`)
- **Frontend Developer** - React, React Native, TypeScript UI development
- **Backend Architect** - API design, database optimization, serverless architecture
- **Mobile App Builder** - iOS/Android app development with Expo/React Native
- **AI Engineer** - LLM integration, embeddings, RAG systems
- **DevOps Automator** - CI/CD, infrastructure as code, monitoring
- **Rapid Prototyper** - Quick MVPs and proof-of-concept builds

### Product (`product/`)
- **Trend Researcher** - Market analysis, competitive intelligence
- **Feedback Synthesizer** - Customer feedback analysis and prioritization
- **Sprint Prioritizer** - Backlog management and sprint planning

### Marketing (`marketing/`)
- **TikTok Strategist** - Viral content strategy for hardware startups
- **Instagram Curator** - Visual content planning and engagement
- **Twitter Engager** - Tech Twitter presence and community building
- **Reddit Community Builder** - Subreddit engagement and growth
- **App Store Optimizer** - ASO, keywords, conversion optimization
- **Content Creator** - Blog posts, documentation, landing pages
- **Growth Hacker** - Viral loops, referral systems, acquisition strategies

### Design (`design/`)
- **UI Designer** - Interface design, component libraries
- **UX Researcher** - User research, usability testing
- **Brand Guardian** - Brand consistency, design systems
- **Visual Storyteller** - Product storytelling through visuals
- **Whimsy Injector** - Delightful micro-interactions and animations

### Project Management (`project-management/`)
- **Experiment Tracker** - A/B tests, feature flags, learning logs
- **Project Shipper** - Release management, launch coordination
- **Studio Producer** - Cross-functional project orchestration

### Studio Operations (`studio-operations/`)
- **Support Responder** - Customer support automation
- **Analytics Reporter** - Metrics dashboards, insights generation
- **Infrastructure Maintainer** - System health monitoring
- **Legal Compliance Checker** - GDPR, privacy, terms validation
- **Finance Tracker** - Expense categorization, budget monitoring

### Testing (`testing/`)
- **Tool Evaluator** - Software vendor assessment
- **API Tester** - Endpoint testing, integration validation
- **Workflow Optimizer** - Process improvement suggestions
- **Performance Benchmarker** - Speed and efficiency testing
- **Test Results Analyzer** - QA report synthesis

## Usage in CentaurOS

Founders can:
1. Browse agents by category in the AI Agents tab
2. Deploy agents to their workspace
3. Configure agent parameters (API keys, goals, constraints)
4. Monitor agent activity and outputs
5. Provide feedback to improve agent performance

## Agent Architecture

Each agent is configured with:
- **Role & Expertise** - What the agent specializes in
- **Tools Available** - Which APIs/services it can access
- **Output Format** - How it delivers results
- **Approval Requirements** - What needs human review
- **Cost per Task** - Transparent AI API usage costs
