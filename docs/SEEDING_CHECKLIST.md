# Seeding Checklist

**App-guided checklist for building your Fractional Foundry directory**

---

## Quick Start (30-60 minutes total)

### Phase 1: Warm Network Seed (15 mins)

- [ ] **Export your network**
  - Export contacts from LinkedIn, CRM, or personal database
  - Create CSV with columns: name, linkedin_url, role_archetype, sector_tags, notes, email

- [ ] **Categorize contacts**
  - Fractional executives (have done or would do fractional work)
  - Advisors (board members, strategic advisors)
  - Apprentice candidates (junior talent you've met)

- [ ] **Prepare upload file**
  - Clean up duplicates
  - Add role_archetypes (see lookup table below)
  - Add sector_tags (see lookup table below)

- [ ] **Upload via Seed Tool**
  - Navigate to WHO Tab → Seed Directory
  - Click "Network Seed Upload"
  - Review dedupe warnings
  - Confirm upload

**Target: 30-50 stubs created**

---

### Phase 2: Event Captures (5 mins)

- [ ] **Add recent event contacts**
  - Think back to last 3-6 months of events
  - Conferences, meetups, dinners

- [ ] **Use Event Seed intake**
  - Tag each batch with event name
  - Quick add: just name + LinkedIn URL

**Target: 10-20 additional stubs**

---

### Phase 3: Generate Invites (10 mins)

- [ ] **Prioritize invite list**
  - High priority: Active fractional execs you know well
  - Medium: Advisors and experienced operators
  - Lower: People you've met once

- [ ] **Generate invite links**
  - Select stubs
  - Click "Generate Invites"
  - Review generated templates

- [ ] **Send invites**
  - Copy email template for those with email
  - Copy LinkedIn DM for others
  - Mark as "sent" after sending

**Target: 25-40 invites sent**

---

### Phase 4: Set Up Apprentice Intake (10 mins)

- [ ] **Review intake form**
  - Check questions match your needs
  - Customize if needed

- [ ] **Share intake form**
  - Copy public URL
  - Share in relevant communities
  - Add to partner communications

- [ ] **Test the flow**
  - Submit a test application
  - Verify task drafts are created

**Target: Intake form live and shared**

---

### Phase 5: Start Partnerships Pipeline (10 mins)

- [ ] **Add top 10 university targets**
  - Use Partner Import or manual add
  - Include careers service contacts

- [ ] **Add top 5 bootcamp/provider targets**
  - Training providers with apprentice programs

- [ ] **Generate outreach tasks**
  - Create task drafts for first wave
  - Confirm tasks in WHAT tab

**Target: 15 partner orgs added, 5 outreach tasks created**

---

### Phase 6: Verify First Opt-ins (Ongoing)

As people complete opt-in:

- [ ] **Review submitted profile**
  - Check LinkedIn matches
  - Verify role claims
  - Look for evidence links

- [ ] **Run verification checklist**
  - LinkedIn confirmed
  - Role history checked
  - At least 1 evidence link (optional)

- [ ] **Set marketplace visibility**
  - Only for verified, quality profiles
  - Start with selective visibility

**Target: First 5 verified profiles within 1 week**

## Status Progression

```
STUB ──invite──► INVITED ──optin──► OPTED_IN ──verify──► VERIFIED
                              │                              │
                              ▼                              ▼
                          [private]                    [marketplace]
```

- **Stub**: Minimal data, private, not searchable
- **Invited**: Invite sent, awaiting response
- **Opted-in**: Person completed profile, still private
- **Verified**: Admin verified, can be marketplace visible

## Troubleshooting

### "My invites aren't converting"

1. Check invite templates are personalized
2. Follow up after 7 days
3. Try different channel (email vs LinkedIn)
4. Ask for referrals instead

### "Getting low-quality applications"

1. Review intake form questions
2. Share in more targeted communities
3. Add qualifying questions
4. Partner with quality training providers

### "Taking too long to verify"

1. Batch verification sessions
2. Simplify checklist
3. Accept lower evidence bar for warm referrals
