All datasets use **JSON format** with consistent schemas:
- Arrays of objects

- Evidence arrays with URLs, dates, confidence scores

### Import Recommendations
```javascript
// Example Supabase schema
create table orgs (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  org_type text not null,
  website text,
  hq_country text,
  regions text[],
  sector_focus text[],
  stage_focus text[],
  capability_tags text[],

  created_at timestamp default now()

create index idx_orgs_type on orgs(org_type);
create index idx_orgs_regions on orgs using gin(regions);
```
